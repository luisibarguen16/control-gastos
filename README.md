# Control de gastos

Programa de consola en Python que registra gastos, calcula qué porcentaje de tu salario has gastado y permite convertir moneda (de pesos a dólares y viceversa).

Los datos se guardan en un archivo JSON, así que no se pierden al cerrar el programa.

## Funciones

1. Agregar gasto
2. Eliminar gasto
3. Ver tus gastos
4. Conversor de moneda
5. Editar salario
6. Salir

## Cómo ejecutarlo

```
python control_de_gastos.py
```

## Archivos que genera

`usuario_gastos.json`: guarda tu salario y tus gastos. Está en el `.gitignore`, así que no se sube a Git.
